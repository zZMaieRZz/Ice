Ice — мощный инструмент для управления строкой меню. Его основная функция — скрывать и показывать элементы строки меню, но проект также стремится предложить множество дополнительных возможностей, чтобы стать одним из самых универсальных инструментов в этой категории.

## Установка

### Установка вручную

Скачайте файл «Ice.zip» со страницы [последнего выпуска](https://github.com/jordanbaird/Ice/releases/latest), распакуйте его и переместите приложение в папку `Applications` («Программы»).

### Homebrew

Установите Ice с помощью следующей команды:

```sh
brew install --cask jordanbaird-ice
```

## Почему Ice поддерживает только macOS 14 и более поздние версии?

Ice использует ряд системных API, доступных начиная с macOS 14. Поэтому поддержка более ранних версий macOS не планируется.
