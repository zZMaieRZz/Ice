# Ice 0.11.13-dev.2 Tahoe RU (ad-hoc)

Сборка на базе upstream **0.11.13-dev.2** с русской локализацией и отключёнными автообновлениями.

## Что внутри

- русский интерфейс (меню статус-итема, настройки, разрешения, разделы, «Запускать при входе»);
- меню **«Язык»** → «Системный» / English / Русский;
- блок обновлений отключён: нет раздела Updates и пункта «Проверить обновления», Sparkle не запускается;
- XPC-сервис `MenuBarItemService` работает в ad-hoc сборке через локальный entitlement-обход;
- исправления macOS 26 из upstream 0.11.13-dev.2: определение исходного процесса элементов, control items, перемещение и кэш изображений.

## Установка

1. Скачайте `Ice-0.11.13-dev.2-tahoe-ru-adhoc.dmg` или `.zip`.
2. Завершите старый Ice: `killall Ice`.
3. Перетащите `Ice.app` в `/Applications`, подтвердите замену.
4. Запустите Ice. Если Gatekeeper блокирует — правый клик → «Открыть» либо:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Ice.app
   ```

5. Выдайте **Accessibility** и, при необходимости, **Screen Recording**:
   - «Системные настройки» → «Конфиденциальность и безопасность» → «Универсальный доступ»;
   - «...» → «Запись экрана».

После выдачи разрешений перезапустите Ice.

## Важно

- Сборка **ad-hoc**, без Developer ID и нотаризации. Gatekeeper будет предупреждать.
- Разрешения Accessibility/Screen Recording привязаны к подписи; после замены ad-hoc сборки их может потребоваться выдать заново.
- Автообновления не настроены; не используйте обновление поверх этой сборки.
- Bundle ID совпадает с upstream (`com.jordanbaird.Ice`), сборка заменяет установленный Ice.
- Это beta-сборка upstream; возможны особенности поведения macOS 26.

codesign --verify --deep --strict /Applications/Ice.app
